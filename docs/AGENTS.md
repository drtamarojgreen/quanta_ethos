# Agent Instructions for PrismQuanta

## Project Overview
PrismQuanta is a principled AI ecosystem built with C++. It follows Chai Driven Development (CDD).

## Key Principles
- **No Stubs**: Implement all features fully.
- **Verification**: Always verify changes with `read_file` or `ls`.
- **Packages**: Use the grouped directory structure (logic, model, ethos, api, data, dev, ux, sec, perf, deploy).

## Build and Test
Run `bash build_all.sh` to compile and `bash test_all.sh` to verify.
